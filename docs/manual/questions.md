# 提问与理解

围绕原文提出问题，选择足够的背景，再通过来源核对回答。局部难点适合解释窗，持续讨论适合右侧对话。

## 解释选区 <!-- explain -->

选中文字或框选图表后，点击「弹窗解释」。按钮下方显示将要使用的模型，也就是输入区当前选择的模型，点击后会立即生成回答。想先换模型，选择「换模型后解释…」：解释窗只打开、不发送，确认模型和强度后再发送。解释窗保留创建时的页码、选区和背景，之后翻页不会改变它正在讨论的内容。

可以在窗内追问，也可以继续选取回答中的文字打开子解释窗。顶部路径用于返回上层；暂时不用的窗口可以最小化，稍后恢复。

需要保留回答时，点击「存为笔记」；需要放入正式会话时，点击「保存为正式对话」。

## 在对话中提问 <!-- chat -->

右侧「对话」可以直接输入问题。选区引用会显示在输入区附近，发送前检查是否仍然需要。Enter 发送，Shift + Enter 换行。

问题尽量写清想解决的困难，例如：“为什么这里需要连续性条件？去掉后会发生什么？”

生成时可以停止，也能继续写下一条问题。向上查看历史时，回答不会强行把页面滚回底部；需要时点击「回到最新」。

## 选择问答范围 <!-- scope -->

输入区左上角的「提问位置」显示这个问题从哪一页出发，默认跟随翻页，点击后可锁定在某一页。通过底部「资料范围」，或「设置」中的「范围」选择在这一页之外还加入哪些资料：

| 范围 | 适合的情况 |
| --- | --- |
| 当前页 | 解释本页定义、公式或图表 |
| 附近页 | 需要前后推导或相邻页面的背景 |
| 整份课件检索 / 课程来源 | 在课件或课程已选来源中寻找相关内容 |

选择「课程来源」时，问题面向整门课：除非锁定了提问位置、选中了文字或框选了区域，否则不会附上当前页的图像和全文。附近页会补充前后各两页的文字；全文检索会寻找相关摘录，并不等于把所有页面图像都发给模型。其他页的视觉细节可通过搜索结果附图补充。

![发送前检查页码、资料范围和模型设置。](/manual/scope.jpg)

范围控制本轮新增资料，已有会话历史仍可能参与回答。需要从新的背景开始时，请新建会话。

## 查看模型实际收到的内容 <!-- evidence -->

问题中的「已发送材料」可查看页面图像、摘录和其他背景。回答中的引用及「来源」用于回到原页核对；悬停或键盘聚焦引用可查看预览。

AI 的解释与原文并不总是一致。检查结论时，尤其留意适用条件、单位、符号和被省略的步骤。来源已删除时，旧记录仍在，但无法打开对应页面。

## 调整回答方式 <!-- options -->

输入区底部依次是助手、模型和资料范围。点击模型按钮（显示为“模型 · 强度”）选择模型，并在同一弹窗中选择思考强度；可用的强度取决于模型。模型列表默认收藏优先；点击「调整顺序」后可用 ↑ ↓ 排列模型，顺序会保存，并同样用于其他页面的模型下拉框，「恢复默认」可撤销。弹窗顶部的「常用配置」可一键切换到预先保存的模型与参数，在 AI 连接中心的「常用配置」中设置；尚未设置时显示设置入口。「设置」用于调整回答长度、问答字号、仅文本、课件工具和联网。

思考强度是模型本身的参数；助手和回答长度通过提示词告诉模型怎样回答，不改变模型参数。课件工具和联网决定模型能否自行检索课件、上网查阅。较长回答并不代表推理一定更准确。「问答字号」可在小、标准、大、特大之间切换，同时作用于问答区和解释窗，保存在当前浏览器，不影响课件和其他界面。

只有文字能力的模型，应启用「仅文本」模式；扫描页、图表和公式细节需要支持图像的模型。[连接与设置](#/manual/settings/models)介绍如何确认能力。

回答下方的快捷追问只会填入草稿，发送后才调用模型。修改问题和重新回答会创建分支，详见[历史与会话](#/manual/history/branches)。
